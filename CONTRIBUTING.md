# Contributing

Open a focused pull request against the relevant branch. Publicity changes
target `release/preview-v0.1`; ongoing experiment fixes target
`codex/gpu-ready-minimal-runner` and are synchronized by traceable commits.

Use a Conventional Commit PR title (`feat:`, `fix:`, `test:`, `docs:`, `chore:`
with an optional scope). Use squash merge after required checks and maintainer
review. No force pushes or direct changes to the protected publicity target.
Do not fabricate author signatures, review approvals or GPU validation.

Describe the scientific workload, evidence, metrics and resume impact. Preserve
old raw attempts; changes to recipes, requests or thresholds require explicit
protocol approval. CPU green is not GPU acceptance. Do not include credentials,
private host paths, raw dataset text, checkpoints or unreviewed experiment files.
Compact allowlisted result summaries may be proposed with provenance and rights
review. Publishing an empirical claim requires the corresponding completed data.

Disclose copied/derived material and licenses. Only contribute code you may
license. New original submissions follow LICENSE; historical and third-party
permissions remain intact. Research findings and independent follow-up work are
welcome. This is a source-available project, not an OSI open-source release.

The sole maintainer manually reviews and merges. We do not require a self-review
approval that GitHub cannot provide or describe machine review as independent.
External PR checks use read-only tokens, no deployment secrets and no paid GPUs.
